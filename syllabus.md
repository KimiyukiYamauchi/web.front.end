## 1. 科目概要

本授業では、素のJavaScript（Vanilla JS）とReactの基礎を短期間で押さえたのち、書籍『Next.js + ヘッドレスCMSではじめるかんたんモダンＷｅｂサイト制作入門』の目次構成に沿ってハンズオンを行い、モダンなWeb制作の一連の流れ（設計・実装・データ管理・デプロイ）を体験する。最終的には、学んだ技術と生成AIを活用しながら、以下の技術要件を満たすオリジナルのWebアプリを個人で企画・開発し、期末制作として提出・発表する。

## 2. 到達目標

1. Vanilla JSの基本文法・DOM操作・非同期処理を理解し、簡単なアプリを実装できる
2. Reactのコンポーネント設計・state管理・スタイリング（CSS Modules）を理解し、実装できる
3. 書籍のハンズオンを通じて、Next.js（App Router / TypeScript / ESLint）の基本構成、レンダリング方式（SSR/SSG/CSR/ISR）、ルーティング、スタイル設定を理解し、実装できる
4. ヘッドレスCMS（microCMS）と連携したデータ駆動型サイトを構築できる
5. GitHubによるソースコード管理、Vercelによるデプロイの一連の流れを実践できる
6. 生成AIを活用しながら、自分なりの要件でWebアプリを企画・実装・説明できる

## 3. 使用技術・教材

- 書籍：『Next.js + ヘッドレスCMSではじめるかんたんモダンＷｅｂサイト制作入門』
- 開発環境：Node.js（LTS）, npm, Visual Studio Code
- フロントエンド：HTML / CSS / JavaScript, React, Next.js（TypeScript, ESLint, App Router）
- スタイリング：globals.css, CSS Modules（Scoped CSS）
- データ管理：microCMS
- フォーム連携：HubSpot
- バージョン管理：GitHub
- デプロイ：Vercel
- 補助教材：現代の JavaScript チュートリアル（https://ja.javascript.info/）
