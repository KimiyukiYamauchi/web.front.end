## 1. イベントハンドリング

### 1.1 基本の書き方

Vanilla JS（第6回）では `addEventListener` でイベントを登録しましたが、Reactでは **JSXの属性としてイベントハンドラを渡す** 書き方をします。

```tsx
function ClickButton() {
  const handleClick = () => {
    console.log("ボタンがクリックされました！");
  };

  return <button onClick={handleClick}>クリックしてね</button>;
}
```

| Vanilla JS | React |
|---|---|
| `element.addEventListener("click", fn)` | `onClick={fn}` |
| `element.addEventListener("change", fn)` | `onChange={fn}` |
| `onclick="doSomething()"`（文字列） | `onClick={doSomething}`（関数そのもの） |

**注意点**：`onClick={handleClick()}` のように `()` をつけて呼び出してしまうと、クリックを待たずに**即座に実行されてしまう**というミスが非常に多いです。「関数そのもの（参照）を渡す」ことを強調してください。

### 1.2 引数を渡したい場合はアロー関数で包む

```tsx
function TaskRow({ id, onDelete }: { id: number; onDelete: (id: number) => void }) {
  return (
    <li>
      タスク{id}
      {/* onDelete(id) をそのまま書くと即実行されてしまうので、アロー関数で包む */}
      <button onClick={() => onDelete(id)}>削除</button>
    </li>
  );
}
```

### 1.3 イベントオブジェクトを受け取る

```tsx
function InputLogger() {
  const handleChange = (e: React.ChangeEvent<HTMLInputElement>) => {
    console.log("入力値:", e.target.value);
  };

  return <input onChange={handleChange} />;
}
```

`e.target.value` で、入力欄の現在の値を取得できます（Vanilla JSの `input.value` に相当）。

## 2. 制御コンポーネント（Controlled Component）

### 2.1 制御コンポーネントとは

入力欄の値を **useStateで管理し**、`value` と `onChange` をセットで使う書き方を「制御コンポーネント」と呼びます。

```tsx
import { useState } from "react";

function ControlledInput() {
  const [text, setText] = useState("");

  return (
    <div>
      <input
        value={text}
        onChange={(e) => setText(e.target.value)}
      />
      <p>入力中: {text}</p>
      <button onClick={() => setText("")}>クリア</button>
    </div>
  );
}
```

- `value={text}`：入力欄の表示内容を **常にstateの値と一致させる**
- `onChange={(e) => setText(e.target.value)}`：入力されるたびにstateを更新する
- こうすることで、「クリアボタンでstateを空にする」といった**プログラム側からの入力欄の操作**ができるようになる

### 2.2 Vanilla JS版との対応

第6回のメモアプリで書いていた処理と比較すると、考え方の違いがよくわかります。

| Vanilla JS（第6回） | React（制御コンポーネント） |
|---|---|
| `document.getElementById("input").value` | `value={text}`（stateから読む） |
| 値を直接読み書きする | `onChange` でstateを更新→画面は自動で追従 |
| `input.value = ""`（クリア） | `setText("")`（stateをクリア→表示も自動更新） |

**ポイント**：「入力欄の値の“正解”は常にstateが持っている。画面（DOM）はstateを映す鏡でしかない」という感覚をつかんでおくと、以降のReact学習がスムーズになります。

## 3. map()によるリスト表示

### 3.1 基本の書き方

第6回で学んだ配列の `map()` メソッド（第6回1.2）を使って、配列のデータをJSXのリストに変換します。

```tsx
function FruitList() {
  const fruits = ["りんご", "ばなな", "みかん"];

  return (
    <ul>
      {fruits.map((fruit, index) => (
        <li key={index}>{fruit}</li>
      ))}
    </ul>
  );
}
```

### 3.2 key属性はなぜ必要か

リストの各要素には、必ず一意な `key` 属性をつける必要があります。

```tsx
type Task = { id: number; text: string };

function TaskList({ tasks }: { tasks: Task[] }) {
  return (
    <ul>
      {tasks.map((task) => (
        // インデックスではなく、データが持つ一意なid（第3〜6回のオブジェクト設計）をkeyにするのが望ましい
        <li key={task.id}>{task.text}</li>
      ))}
    </ul>
  );
}
```

- `key` は、Reactが「どの要素がどれに対応するか」を効率よく判定するための目印
- `key` がないと、コンソールに警告が出るだけでなく、削除・並び替え時に表示がおかしくなることがある
- 可能な限り **配列のインデックスではなく、データが持つ一意なID** を使うのが推奨（要素の追加・削除で順番が変わってもズレない）

### 3.3 オブジェクトの配列をstateで管理する

```tsx
import { useState } from "react";

type Task = { id: number; text: string; completed: boolean };

function TaskApp() {
  const [tasks, setTasks] = useState<Task[]>([
    { id: 1, text: "牛乳を買う", completed: false },
    { id: 2, text: "宿題をする", completed: true },
  ]);

  const toggleTask = (id: number) => {
    // 元の配列は変更せず、mapで新しい配列を作ってsetTasksに渡す（第6回の復習）
    setTasks(
      tasks.map((task) =>
        task.id === id ? { ...task, completed: !task.completed } : task
      )
    );
  };

  return (
    <ul>
      {tasks.map((task) => (
        <li
          key={task.id}
          style={{ textDecoration: task.completed ? "line-through" : "none" }}
          onClick={() => toggleTask(task.id)}
        >
          {task.text}
        </li>
      ))}
    </ul>
  );
}
```

**重要**：`tasks.push(...)` や `task.completed = true` のように元の配列・オブジェクトを直接書き換えてはいけません。必ずスプレッド演算子（第3回）や `map` / `filter`（第6回）で**新しい配列を作って** `setTasks` に渡します。

## 4. CSS Modules（Scoped CSS）

### 4.1 なぜCSS Modulesが必要か

通常のCSSは、クラス名がプロジェクト全体で共有されるため、別のコンポーネントで同じクラス名（例：`.title`）を使うとスタイルが衝突することがあります。CSS Modulesを使うと、**クラス名がコンポーネントごとに自動的にスコープ化（衝突しないよう変換）** されます。

### 4.2 基本の使い方

ファイル名を `〇〇.module.css` にすると、CRAが自動的にCSS Modulesとして扱います。

`Card.module.css`：

```css
.card {
  border: 1px solid #ccc;
  border-radius: 8px;
  padding: 16px;
}

.title {
  font-size: 20px;
  font-weight: bold;
  color: #333;
}
```

`Card.tsx`：

```tsx
import styles from "./Card.module.css";

function Card({ title }: { title: string }) {
  return (
    <div className={styles.card}>
      <h3 className={styles.title}>{title}</h3>
    </div>
  );
}

export default Card;
```

- `import styles from "./Card.module.css"` で、CSSファイルを **オブジェクトとして** 読み込む
- `styles.card` は `.card` に対応する、実際には `Card_card__a1B2c` のような**自動生成された一意なクラス名**
- 別のコンポーネントで `.card` というクラス名を使っても、内部的には別名に変換されるため**衝突しない**

### 4.3 複数のクラスを組み合わせる

```tsx
import styles from "./TaskItem.module.css";

function TaskItem({ text, completed }: { text: string; completed: boolean }) {
  // 条件によってクラスを切り替えたいときは、テンプレート文字列で結合する
  const className = completed
    ? `${styles.item} ${styles.completed}`
    : styles.item;

  return <li className={className}>{text}</li>;
}
```

`TaskItem.module.css`：

```css
.item {
  padding: 8px;
  border-bottom: 1px solid #eee;
}

.completed {
  text-decoration: line-through;
  color: grey;
}
```

**ポイント**：「グローバルCSS（`globals.css` のようなファイル）」と「CSS Modules（コンポーネント単位）」の使い分けは、第10回以降のNext.jsハンズオンでも継続して出てくる重要な考え方です。ここで基礎を固めておきましょう。

## 5. 総合演習：買い物リストコンポーネント

イベント処理・制御コンポーネント・`map()`・CSS Modulesをすべて組み合わせて、買い物リストアプリを作ります。**このアプリの構造は、そのまま第9回のメモアプリの土台になります。**

### 完成イメージ

- 入力欄にアイテム名を入力できる（制御コンポーネント）
- 「追加」ボタンでリストに追加される（イベント処理・state更新）
- 一覧が `map()` で表示される
- CSS Modulesで見た目を整える

```tsx
import { useState } from "react";
import styles from "./ShoppingList.module.css";

type Item = { id: number; name: string };

function ShoppingList() {
  const [items, setItems] = useState<Item[]>([]);
  const [inputText, setInputText] = useState("");

  const handleAdd = () => {
    if (inputText.trim() === "") return;

    setItems([...items, { id: Date.now(), name: inputText }]);
    setInputText("");
  };

  const handleDelete = (id: number) => {
    setItems(items.filter((item) => item.id !== id));
  };

  return (
    <div className={styles.container}>
      <h2 className={styles.title}>買い物リスト</h2>
      <input
        className={styles.input}
        value={inputText}
        onChange={(e) => setInputText(e.target.value)}
        placeholder="アイテムを入力"
      />
      <button className={styles.addButton} onClick={handleAdd}>
        追加
      </button>

      <ul className={styles.list}>
        {items.map((item) => (
          <li key={item.id} className={styles.listItem}>
            {item.name}
            <button onClick={() => handleDelete(item.id)}>削除</button>
          </li>
        ))}
      </ul>
    </div>
  );
}

export default ShoppingList;
```

`ShoppingList.module.css`（例）：

```css
.container {
  max-width: 400px;
  margin: 0 auto;
}

.title {
  font-size: 24px;
}

.input {
  padding: 8px;
  margin-right: 8px;
}

.addButton {
  padding: 8px 16px;
}

.list {
  list-style: none;
  padding: 0;
  margin-top: 16px;
}

.listItem {
  display: flex;
  justify-content: space-between;
  padding: 8px;
  border-bottom: 1px solid #eee;
}
```
