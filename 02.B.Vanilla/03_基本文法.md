## 1. 変数とデータ型

### 1.1 変数の宣言（let）と定数の宣言（const）

JavaScriptでは、値が変わる可能性があるものは `let`、変わらないものは `const` で宣言します。今はほとんどのケースで `const` を基本とし、再代入が必要な場合だけ `let` を使うのが推奨スタイルです。

```js
let message = "Hello, world!";
message = "Hello, JavaScript!"; // letは再代入できる
console.log(message);

const PI = 3.14159;
// PI = 3.14; // エラーになる（constは再代入不可）
console.log(PI);
```

### 1.2 ブロックスコープ

`let` と `const` は「ブロックスコープ」を持ちます。`{ }` の外からは参照できません。

```js
if (true) {
  let message = "ブロックの中";
  console.log(message); // OK
}
console.log(message); // ReferenceError: message is not defined
```

### 1.3 主なデータ型

| 型        | 説明                   | 例                          |
| --------- | ---------------------- | --------------------------- |
| Number    | 整数・小数             | `let age = 25;`             |
| String    | 文字列                 | `let name = "田中";`        |
| Boolean   | true / false           | `let isStudent = true;`     |
| undefined | 値が未代入             | `let value;`                |
| null      | 意図的に空             | `let obj = null;`           |
| Object    | 複数の値をまとめたもの | `{ name: "John", age: 30 }` |
| Array     | 順序付きのデータ集合   | `[1, 2, 3]`                 |

```js
let person = { name: "John", age: 30, occupation: "Developer" };
console.log(person.name); // John

let numbers = [1, 2, 3, 4, 5];
console.log(numbers[0]); // 1
```

JavaScriptは「動的型付け言語」なので、変数の型は代入した値によって決まります。

```js
let value = 42;
console.log(typeof value); // "number"
value = "Hello";
console.log(typeof value); // "string"
```

**やってみよう**：自分の名前・年齢・出身地を持つオブジェクトを `const profile = {...}` として作り、`console.log` で表示してみましょう。

## 2. 分割代入とスプレッド演算子

### 2.1 分割代入（Destructuring）

配列やオブジェクトから、必要な値だけを取り出して変数に代入できます。

```js
// 配列の分割代入
const numbers = [1, 2, 3, 4, 5];
const [a, b, ...rest] = numbers;
console.log(a); // 1
console.log(b); // 2
console.log(rest); // [3, 4, 5]

// オブジェクトの分割代入
const person = { name: "Alice", age: 30, occupation: "Engineer" };
const { name, age } = person;
console.log(`Name: ${name}, Age: ${age}`);
```

### 2.2 スプレッド演算子（`...`）

配列やオブジェクトを展開して、結合やコピーを簡単に行えます。

```js
// 配列の結合・複製
const arr1 = [1, 2, 3];
const arr2 = [4, 5, 6];
const combined = [...arr1, ...arr2];
console.log(combined); // [1, 2, 3, 4, 5, 6]

const copiedArr = [...arr1]; // 複製（元の配列は変更されない）

// オブジェクトの結合・複製
const obj1 = { a: 1, b: 2 };
const obj2 = { c: 1, d: 2 };
const mergedObj = { ...obj1, ...obj2 };
console.log(mergedObj); // { a: 1, b: 2, c: 1, d: 2 }
```

**ポイント**：分割代入・スプレッド演算子はReact（第7回〜）のpropsやstate更新で頻出します。ここでしっかり慣れておくと後が楽になります。

## 3. 演算子

| 種類       | 演算子                    | 例                     |
| ---------- | ------------------------- | ---------------------- |
| 算術演算子 | `+ - * / % ++ --`         | `10 % 3 // 1`          |
| 代入演算子 | `= += -= *= /= %=`        | `x += 5`               |
| 比較演算子 | `== != === !== > < >= <=` | `10 === "10" // false` |
| 論理演算子 | `&& \|\| !`               | `x && y`               |

### 3.1 `==` と `===` の違い（重要）

```js
let x = 10;
let y = "10";

console.log(x == y); // true  （型変換して比較）
console.log(x === y); // false （型まで含めて比較）
```

**必ず `===` / `!==`（厳密等価）を使う**ことを徹底しましょう。`==` はバグの温床になりやすい点を強調してください。

## 4. 制御構文（if / switch / for / while）

### 4.1 if文

```js
let age = 20;
if (age < 18) {
  console.log("未成年です");
} else {
  console.log("成人です");
}
```

### 4.2 switch文

```js
let fruit = "apple";
switch (fruit) {
  case "apple":
    console.log("これはリンゴです。");
    break;
  case "banana":
    console.log("これはバナナです。");
    break;
  default:
    console.log("これは未知の果物です。");
}
```

### 4.3 for文 / while文 / do...while文

```js
for (let i = 0; i < 5; i++) {
  console.log(i);
}

let i = 0;
while (i < 5) {
  console.log(i);
  i++;
}

let j = 0;
do {
  console.log(j);
  j++;
} while (j < 5);
```

### 4.4 break / continue

```js
for (let i = 0; i < 5; i++) {
  if (i === 3) break; // ループを抜ける
  console.log(i);
}

for (let i = 0; i < 5; i++) {
  if (i === 3) continue; // このループだけスキップ
  console.log(i);
}
```

### 4.5（発展）エラーハンドリング：try...catch

演習の計算機アプリで使うので、ここで簡単に触れておきます。

```js
try {
  const result = riskyFunction(); // エラーが起きるかもしれない処理
  console.log("結果:", result);
} catch (error) {
  console.error("エラーが発生しました:", error.message);
} finally {
  console.log("処理が完了しました。"); // 成功・失敗に関わらず実行
}
```

## 5. 総合演習：簡単な計算機アプリ

ここまでの内容（データ型、演算子、制御構文、try...catch）を組み合わせて、簡単な計算機アプリを作成します。

### 完成イメージ

- 2つの数値を入力する
- 演算子（+, -, ×, ÷）をプルダウンで選択する
- 「計算」ボタンを押すと結果が表示される
- 未入力・数値以外の入力・0での除算はエラーメッセージを表示する

### 実装例（`calculator.html`）

```html
<!doctype html>
<html lang="ja">
  <head>
    <meta charset="UTF-8" />
    <title>簡単な計算機アプリ</title>
  </head>
  <body>
    <h1>簡単な計算機アプリ</h1>
    <input type="number" id="num1" placeholder="数値1" />
    <select id="operation">
      <option value="add">+</option>
      <option value="subtract">-</option>
      <option value="multiply">×</option>
      <option value="divide">÷</option>
    </select>
    <input type="number" id="num2" placeholder="数値2" />
    <button onclick="calculate()">計算</button>
    <p id="result"></p>

    <script>
      function calculate() {
        try {
          const num1Input = document.getElementById("num1").value;
          const num2Input = document.getElementById("num2").value;

          if (num1Input === "" || num2Input === "") {
            throw new Error("数値を入力してください");
          }

          const num1 = parseFloat(num1Input);
          const num2 = parseFloat(num2Input);

          if (isNaN(num1) || isNaN(num2)) {
            throw new Error("正しい数値を入力してください");
          }

          const operation = document.getElementById("operation").value;
          let result;

          switch (operation) {
            case "add":
              result = num1 + num2;
              break;
            case "subtract":
              result = num1 - num2;
              break;
            case "multiply":
              result = num1 * num2;
              break;
            case "divide":
              if (num2 === 0) {
                throw new Error("0で割ることはできません");
              }
              result = num1 / num2;
              break;
            default:
              throw new Error("無効な演算子です");
          }

          document.getElementById("result").textContent = `結果: ${result}`;
        } catch (error) {
          document.getElementById("result").textContent =
            `エラー: ${error.message}`;
        }
      }
    </script>
  </body>
</html>
```

### 発展課題（時間が余ったら）

- 演算結果を小数点第2位までに丸めて表示する（`toFixed(2)`）
- 「クリア」ボタンを追加し、入力欄と結果をリセットする
- 計算履歴を配列に保存し、画面下部に一覧表示する（第6回の配列操作の予告にもなります）
