## 1. クラス構文とインスタンス生成

### 1.1 クラスの定義

`class` を使うと「同じ形のデータ」と「そのデータに対する処理」をひとまとめにできます。

```js
class Person {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }

  greet() {
    console.log(`Hello, my name is ${this.name}`);
  }

  sayAge() {
    console.log(`I am ${this.age} years old`);
  }
}
```

- `constructor` は、インスタンスを作るときに一度だけ呼ばれる特別なメソッドです。
- `this` は「今作られているインスタンス自身」を指します。

### 1.2 インスタンスの生成とメソッドの呼び出し

```js
const person1 = new Person("Alice", 30);
const person2 = new Person("Bob", 25);

person1.greet(); // Hello, my name is Alice
person1.sayAge(); // I am 30 years old
person2.greet(); // Hello, my name is Bob
```

**ポイント**：`class Person` は「設計図」、`new Person(...)` でできた `person1` `person2` は「その設計図から作られた実体（インスタンス）」。

### 1.3 静的メソッド（static）

インスタンスを作らなくても、クラス自体から直接呼び出せるメソッドです。

```js
class MathUtils {
  static square(x) {
    return x * x;
  }
}

console.log(MathUtils.square(5)); // 25
```

## 2. オブジェクト指向の3原則

### 2.1 カプセル化

オブジェクトの内部状態（データ）を外から自由に書き換えられないようにする考え方です。`#` をつけると「プライベートフィールド」になり、クラスの外から直接アクセスできなくなります。

```js
class BankAccount {
  #balance = 0; // プライベートフィールド（クラスの外からは触れない）

  constructor(initialBalance) {
    this.#balance = initialBalance;
  }

  deposit(amount) {
    if (amount > 0) {
      this.#balance += amount;
      console.log(`Deposited: ${amount}. New balance: ${this.#balance}`);
    } else {
      console.log("Deposit amount must be positive.");
    }
  }

  withdraw(amount) {
    if (amount > 0 && amount <= this.#balance) {
      this.#balance -= amount;
      console.log(`Withdrew: ${amount}. New balance: ${this.#balance}`);
    } else {
      console.log(
        "Withdrawal amount must be positive and less than or equal to the current balance.",
      );
    }
  }

  getBalance() {
    return this.#balance;
  }
}

const account = new BankAccount(1000);
account.deposit(500); // Deposited: 500. New balance: 1500
account.withdraw(2000); // Withdrawal amount must be...
// console.log(account.#balance); // エラー：外からアクセスできない
console.log(account.getBalance()); // 1500（公開されたメソッド経由でなら取得できる）
```

**なぜ大事か**：もし `#balance` を外から自由に書き換えられたら、マイナス残高のような「あり得ないデータ」が簡単に作れてしまいます。カプセル化は、データを不正な状態にしないための防御策です。

### 2.2 継承（`extends`, `super`）

既存のクラスの機能を引き継いで、新しいクラスを作る仕組みです。

```js
class Animal {
  constructor(name) {
    this.name = name;
  }

  speak() {
    console.log(`${this.name} makes a noise.`);
  }
}

class Dog extends Animal {
  bark() {
    console.log("わんわん");
  }
}

const dog = new Dog("ぽち");
dog.speak(); // ぽち makes a noise.（親クラスのメソッドをそのまま使える）
dog.bark(); // わんわん（子クラス独自のメソッド）
```

`super(...)` を使うと、子クラスのコンストラクタから親クラスのコンストラクタを呼び出せます（図形描画アプリで実際に使います）。

### 2.3 ポリモーフィズム（多態性）

親クラスと同じ名前のメソッドを子クラスで**上書き（オーバーライド）**することで、呼び出し方は同じでも実際の動きを変えられる仕組みです。

```js
class Person {
  constructor(name) {
    this.name = name;
  }

  greet() {
    console.log(`Hello, my name is ${this.name}.`);
  }
}

class Student extends Person {
  constructor(name, grade) {
    super(name);
    this.grade = grade;
  }

  // 親クラスのgreetを上書き（オーバーライド）
  greet() {
    console.log(
      `Hello, my name is ${this.name}, and I'm in grade ${this.grade}.`,
    );
  }

  study() {
    console.log(`${this.name} is studying in grade ${this.grade}.`);
  }
}

const people = [new Person("Alice"), new Student("Bob", "A")];

// 同じ greet() の呼び方でも、実体（インスタンス）によって動きが変わる
people.forEach((p) => p.greet());
// Hello, my name is Alice.
// Hello, my name is Bob, and I'm in grade A.
```

**ポイント**：「同じ命令（`greet()`）を送っても、相手（インスタンス）によって反応が変わる」のがポリモーフィズムです。図形描画アプリの `draw()` メソッドが、まさにこの考え方で作られています。

## 3. プロトタイプ

`class` 構文は、実は昔からある「プロトタイプ」という仕組みを読みやすく書き直したものです（シンタックスシュガー）。`class` が生まれる前は、次のように書いていました。

```js
function Person(name, age) {
  this.name = name;
  this.age = age;
}

// メソッドをプロトタイプに追加
Person.prototype.greet = function () {
  console.log(`Hello, my name is ${this.name} and I am ${this.age} years old.`);
};

const person1 = new Person("Alice", 30);
const person2 = new Person("Bob", 25);

person1.greet(); // Hello, my name is Alice and I am 30 years old.
person2.greet(); // Hello, my name is Bob and I am 25 years old.

// greetメソッドはプロトタイプに1つだけ存在し、全インスタンスで共有されている
console.log(person1.greet === person2.greet); // true
```

**ポイント**：`class` で書いたメソッドも、実際には裏側でこの「プロトタイプ」に登録されています。「インスタンスごとにメソッドのコピーが作られているわけではなく、1つのメソッドをみんなで共有している」という点を意識すると、`class` の中身への理解が深まります。

## 4. 総合演習：図形描画アプリケーション

継承・ポリモーフィズムの理解を定着させるため、Canvas上に複数の図形を描画するアプリを作ります。

### 完成イメージ

- `Shape` という基本クラスを継承した `Circle`・`Rectangle`・`Triangle` を作る
- それぞれが自分の `draw()` メソッドを持ち、呼び出し方は共通でも描かれる図形が異なる（ポリモーフィズムの実践）

```html
<!doctype html>
<html lang="ja">
  <head>
    <meta charset="UTF-8" />
    <title>図形描画アプリケーション</title>
  </head>
  <body>
    <h1>図形描画アプリケーション</h1>
    <canvas
      id="canvas"
      width="500"
      height="500"
      style="border: 1px solid #000000"
    ></canvas>
    <script>
      // 図形の基本クラス
      class Shape {
        constructor(x, y, color) {
          this.x = x;
          this.y = y;
          this.color = color;
        }
        draw(ctx) {
          // サブクラスでオーバーライドされる
        }
      }

      class Circle extends Shape {
        constructor(x, y, radius, color) {
          super(x, y, color);
          this.radius = radius;
        }
        draw(ctx) {
          ctx.beginPath();
          ctx.arc(this.x, this.y, this.radius, 0, 2 * Math.PI);
          ctx.fillStyle = this.color;
          ctx.fill();
        }
      }

      class Rectangle extends Shape {
        constructor(x, y, width, height, color) {
          super(x, y, color);
          this.width = width;
          this.height = height;
        }
        draw(ctx) {
          ctx.fillStyle = this.color;
          ctx.fillRect(this.x, this.y, this.width, this.height);
        }
      }

      class Triangle extends Shape {
        constructor(x, y, base, height, color) {
          super(x, y, color);
          this.base = base;
          this.height = height;
        }
        draw(ctx) {
          ctx.beginPath();
          ctx.moveTo(this.x, this.y);
          ctx.lineTo(this.x + this.base / 2, this.y + this.height);
          ctx.lineTo(this.x - this.base / 2, this.y + this.height);
          ctx.closePath();
          ctx.fillStyle = this.color;
          ctx.fill();
        }
      }

      const canvas = document.getElementById("canvas");
      const ctx = canvas.getContext("2d");

      const shapes = [
        new Circle(100, 100, 50, "red"),
        new Rectangle(200, 200, 100, 50, "blue"),
        new Triangle(300, 300, 80, 60, "green"),
      ];

      // shapes配列の中身が何であっても、同じ shape.draw(ctx) で呼び出せる
      shapes.forEach((shape) => shape.draw(ctx));
    </script>
  </body>
</html>
```

### 発展課題（時間が余ったら）

- `Shape` に `move(dx, dy)` メソッドを追加し、全図形で座標を移動できるようにする

- `Circle` に「半径をランダムにする」static メソッドを追加してみる
