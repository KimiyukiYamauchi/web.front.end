## 1. 関数の定義・引数・返り値

### 1.1 関数の定義と呼び出し

```js
function greet(name) {
  console.log(`Hello, ${name}!`);
}

greet("Alice"); // Hello, Alice!
```

### 1.2 引数と返り値

```js
function add(a, b) {
  return a + b;
}

const result = add(2, 3);
console.log(result); // 5
```

### 1.3 デフォルト引数・レストパラメータ

```js
function greet(name = "Guest") {
  return `Hello, ${name}!`;
}
console.log(greet()); // "Hello, Guest!"
console.log(greet("Bob")); // "Hello, Bob!"

function sum(...numbers) {
  return numbers.reduce((acc, curr) => acc + curr, 0);
}
console.log(sum(1, 2, 3)); // 6
console.log(sum(4, 5, 6, 7)); // 22
```

### 1.4 関数の引数としてのスプレッド演算子

```js
function sum(a, b, c) {
  return a + b + c;
}
const numbers = [1, 2, 3];
console.log(sum(...numbers)); // 6（配列を展開して渡す）

console.log(Math.max(...[1, 5, 3])); // 5
```

### 1.5 アロー関数

第3回・関数式の復習も兼ねて、書き方の違いを比較します。

```js
// 従来の関数式
const multiply1 = function (a, b) {
  return a * b;
};

// アロー関数（基本形）
const multiply2 = (a, b) => {
  return a * b;
};

// アロー関数（1行に省略した形。returnも{}も省略できる）
const multiply3 = (a, b) => a * b;

console.log(multiply1(2, 3), multiply2(2, 3), multiply3(2, 3)); // すべて6
```

**アロー関数の注意点**

- `arguments` オブジェクトが使えない（代わりにレストパラメータ `...args` を使う）
- `new` でコンストラクタとして使えない
- `this` の扱いが通常の関数と異なる（次回以降、クラスやReactのイベント処理で意識することになります）

## 2. スコープ

| スコープ                         | 説明                                    |
| -------------------------------- | --------------------------------------- |
| グローバルスコープ               | どこからでも参照できる                  |
| 関数スコープ（ローカルスコープ） | 関数の中でだけ有効                      |
| ブロックスコープ                 | `{ }` の中でだけ有効（`let` / `const`） |

```js
const globalVal = "グローバル変数";
function printGlobal() {
  console.log(globalVal); // 参照できる
}
printGlobal();
console.log(globalVal);

function printLocal() {
  const localVar = "ローカル変数";
  console.log(localVar);
}
printLocal();
// console.log(localVar); // ReferenceError: 関数の外からは見えない

if (true) {
  let blockVar = "ブロック変数";
  console.log(blockVar);
}
// console.log(blockVar); // ReferenceError: ブロックの外からは見えない
```

**ポイント**：「変数は、宣言された `{ }` の中でしか使えない」

## 3. コールバック関数

「関数の引数として渡す関数」のことをコールバック関数と呼びます。「処理が終わったら、この関数を呼んでね」という使い方をします。

```js
function fetchData(callback) {
  // 実際のデータ取得処理の代わりに、疑似的な処理
  const data = "取得したデータ";
  callback(data);
}

function processData(data) {
  console.log("取得したデータ: " + data);
}

fetchData(processData); // "取得したデータ: 取得したデータ"
```

### 時間がかかる処理を模した例（`setTimeout`）

```js
function fetchData(callback) {
  setTimeout(() => {
    const data = "取得したデータ";
    callback(data);
  }, 1000); // 1秒後に呼ばれる
}

console.log("データの取得を開始...");
fetchData((data) => {
  console.log("取得したデータ: " + data);
});
console.log("データの取得を待っています...");

// 出力順序に注目：
// 1. "データの取得を開始..."
// 2. "データの取得を待っています..."
// 3.（1秒後）"取得したデータ: 取得したデータ"
```

ここで「JavaScriptは処理を待たずに次の行に進む（非同期）」という感覚をつかんでもらうのが重要です。

## 4. 非同期処理の基本：Promise・async/await

コールバックが何重にも重なると読みにくくなる（コールバック地獄）ため、**Promise** という仕組みが導入されました。

### 4.1 Promiseの基本

```js
function fetchData() {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      const success = true; // 成功したと仮定
      if (success) {
        resolve("データの取得に成功しました");
      } else {
        reject("エラーが発生しました");
      }
    }, 1000);
  });
}

fetchData()
  .then((data) => {
    console.log(data); // 成功時
  })
  .catch((error) => {
    console.error(error); // 失敗時
  })
  .finally(() => {
    console.log("処理が完了しました"); // 必ず実行される
  });
```

### 4.2 async/await（Promiseをより読みやすく書く構文）

```js
async function getData() {
  try {
    const result = await fetchData(); // Promiseが解決されるまで待つ
    console.log(result);
  } catch (error) {
    console.error(error);
  } finally {
    console.log("処理が完了しました");
  }
}

getData();
```

**ポイント**：`async/await` は「Promiseを、まるで同期処理のように上から順番に読めるようにする書き方」です。`try...catch` で失敗時の処理を書けるのも、第3回のエラーハンドリングとのつながりです。

## 5. 総合演習：ToDoリストアプリ

今日学んだ「関数」「スコープ」「配列（`push`, `forEach` は次回本格的に扱いますが軽く使用）」を組み合わせて、シンプルなToDoリストアプリを作成します。

```html
<!doctype html>
<html lang="ja">
  <head>
    <meta charset="UTF-8" />
    <title>ToDo リスト</title>
  </head>
  <body>
    <h1>ToDo リスト</h1>
    <input type="text" id="new-task" placeholder="新しいタスクを入力" />
    <button onclick="addTodo()">タスクを追加</button>
    <ul id="task-list"></ul>

    <script>
      let todoList = [];

      function addTodo() {
        const input = document.getElementById("new-task");

        if (input.value.trim() === "") {
          alert("タスクを入力してください");
          return;
        }

        todoList.push({ text: input.value, completed: false });
        input.value = "";
        renderTodoList();
      }

      function renderTodoList() {
        const taskList = document.getElementById("task-list");
        taskList.innerHTML = "";

        todoList.forEach((todo, index) => {
          const li = document.createElement("li");
          li.innerHTML = `
            <input type="checkbox" ${todo.completed ? "checked" : ""} onclick="toggleComplete(${index})">
            ${todo.text}
            <button onclick="deleteTodo(${index})">削除</button>
          `;
          taskList.appendChild(li);
        });
      }

      const toggleComplete = (index) => {
        todoList[index].completed = !todoList[index].completed;
        renderTodoList();
      };

      const deleteTodo = (index) => {
        todoList.splice(index, 1);
        renderTodoList();
      };
    </script>
  </body>
</html>
```

### 発展課題（時間が余ったら）

- タスク追加時に `fetchData` 風の関数を使い、「1秒後に追加される」演出をasync/awaitで実装してみる
- 完了済みタスクに取り消し線をつける（CSSの `text-decoration: line-through`）
- タスク数を画面に表示する（`todoList.length`）
